# ZTAN Century Survivability Reader (Century Replayer)

A pure, standalone, zero-dependency forensic archaeology replayer designed to survive the next 100 years of browser engine evolution, Content Security Policy (CSP) tightenings, and dependency rot.

## 🛡️ Survivability Guarantees

*   **Zero Dependencies**: No `npm install`, no Webpack/Vite build steps, no external CDN requests.
*   **Acyclic & Isolated**: Lives completely outside of package-manager registry dependency lines.
*   **Web API Native**: Utilizes basic, standardized HTML5 DOM elements, standard CSS variables, and the standard Web Crypto API (`crypto.subtle`) available natively in all modern browser engines since 2015.
*   **SVG-Only Rendering**: Renders transaction chronology timelines purely inside scalable vector graphic (SVG) primitives, shielding it from Canvas/WebGL deprecations.

## 🚀 How to Execute

Simply double-click `index.html` (or open it via `file://` protocol in any compliant browser).

No HTTP server is required! It works perfectly:
1.  In air-gapped environments.
2.  On highly restrictive secure browser boundaries.
3.  Fully offline (with complete physical network disconnection).

### Forensic Ingestion Procedure
1.  Open `index.html` in your browser.
2.  Drag and drop any ZTAN `.json` forensic capsule (generated by the `OfflineCapsuleBuilder` or similar archaeology systems) into the drop zone.
3.  Alternatively, click **"Preload Capsule Demo"** in the top navigation bar to load an interactive validation dataset.
4.  Navigate to `verify.html` (Chain Verifier) to recalculate transaction SHA-256 checksums client-side to verify total data integrity.
