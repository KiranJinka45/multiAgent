# Failure Incident Template
# Copy this directory structure for each new failure

## Directory: /failures/<incident-id>/

### Required Files:
# - incident.md     — Human-readable incident description
# - trace.json      — Raw trace file at time of failure
# - env.json        — Environment snapshot
# - replay-result.json — Replay verification output
# - root-cause.md   — Post-mortem root cause analysis
