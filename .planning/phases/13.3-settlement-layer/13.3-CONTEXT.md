# Context: Phase 13.3 — Global Governance Settlement Layer

## Objective
Finalize the settlement of institutional breaches onto public, decentralized trust anchors to ensure immutable, non-repudiable evidence of slashing events.

## Requirements
- **Settlement Layer Adapter**:
    - Initialize `packages/settlement-layer`.
    - Implement `PublicAnchorAdapter` for external chain interaction (simulated for V1).
- **Finality Proofs**:
    - Implement `SettlementManager`: Handles the transition from internal slashing to public settlement.
    - Generate `SettlementProof` (Merkle proof of slashing event).
- **CLI (ztanctl)**:
    - `settle status`: View pending and finalized settlements.
    - `settle archive`: Push finalized events to a permanent storage.
- **Verification**:
    - Automated proof verification against the simulated public anchor.

## Current State
- `staking-core` and `slashing-engine` are operational.
- No logic for external settlement exists.
