# Phase 9, Plan 1: Bare-Metal Portability Verification

## Objective

Validate that the ZTAN External Verification Kit (`verify-kit`) compiles, executes, and yields correct cryptographic validation assertions on bare-metal architectures, ensuring that any third-party operator or auditor can successfully verify ZTAN audit proofs under physical hardware execution environments (requirement `OPS-MAINT-PORT-01`).

---

## Tasks

<task id="9.1.1">
<title>Create Bare-Metal Runbook (BARE_METAL_PORTABILITY_VERIFICATION.md)</title>
<action>
Create `BARE_METAL_PORTABILITY_VERIFICATION.md` at the workspace root to document:
- The physical host hardware baseline (non-virtualized Linux CPU VT-x/AMD-V).
- Python environment prerequisites (Python 3.9+, pip dependencies `py_ecc`, `cryptography`).
- Command instructions to run automated verification tools.
- SRE auditing checklist for physical hardware and cryptographic proof checks.
</action>
<acceptance_criteria>
- File `BARE_METAL_PORTABILITY_VERIFICATION.md` is successfully written.

<task id="9.1.2">
<title>Implement Bare-Metal Validation Runner (scripts/validate-bare-metal-kit.ts)</title>
<action>
Write `scripts/validate-bare-metal-kit.ts` to automate host checks:
- Verify `/dev/kvm` presence (non-blocking warning if missing/virtualized).
- Inspect node and python runtime versions.
- Check pip package availability (`py_ecc`, `cryptography`).
- Generate fresh DKG vectors and bundle via `node verify-kit/v1.5/generate-vectors.mjs`.
- Execute `verify-kit/v1.5/verify.py` on the generated vectors/bundle.
- Execute `verify-kit/auditor.py` on the generated bundle.
- Write audit results to `BARE_METAL_VALIDATION_REPORT.json`.
</action>
<acceptance_criteria>
- Script `scripts/validate-bare-metal-kit.ts` is created and passes typecheck.
- Can be executed using `npx tsx scripts/validate-bare-metal-kit.ts`.
</acceptance_criteria>
</task>

<task id="9.1.3">
<title>Run Validation Runner and Verify Results</title>
<action>
Execute the automated validator locally:
```bash
npx tsx scripts/validate-bare-metal-kit.ts
```
Confirm that:
- DKG test vector generation succeeds.
- Python verification of `vectors.json` and `bundle.json` completes with exit code 0.
- `BARE_METAL_VALIDATION_REPORT.json` is generated with a clean report summary.
</action>
<acceptance_criteria>
- The validation runner executes to completion and logs success.
- `BARE_METAL_VALIDATION_REPORT.json` exists and shows 100% test success.

</task>
