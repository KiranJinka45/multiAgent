# Context: Phase 13.1 — Staked Institutional Governance

## Objective
Anchor institutional governance in direct economic consequence by requiring federations to lock liquid assets (ZTAN) as collateral.

## Requirements
- **Documentation**: Create `docs/STAKED_GOVERNANCE_SPEC.md` with `StakeCertificate` schema and `UnbondingPolicy`.
- **Staking Core**:
    - Initialize `packages/staking-core`.
    - Implement `StakeManager` (Locking & Tracking).
    - Implement `WeightCalculator` (Stake-to-Weight mapping).
    - Implement `CooldownTimer` (Withdrawal enforcement).
- **CLI (ztanctl)**:
    - `stake deposit`
    - `stake status`
    - `stake withdraw`
- **Verification**:
    - Unit tests for locking and weight calculation.
    - Integration tests for cooldown enforcement.
    - Snyk security scan.

## Current State
- `packages/staking-core` exists but is skeletal.
- `packages/ztanctl` has mock `stake` commands.
- `docs/STAKED_GOVERNANCE_SPEC.md` exists but is a draft.
