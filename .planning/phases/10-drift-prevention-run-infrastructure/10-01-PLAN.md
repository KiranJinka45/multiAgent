# Phase 10, Plan 1: Drift Prevention Run Infrastructure

## Objective

Implement an automated test runner script that periodically runs compatibility and reproducibility checks on ZTAN evidence files and audits ecosystem/constitutional drift, triggering structured alerts upon validation mismatches (requirement `OPS-MAINT-DRIFT-01`).

---

## Tasks

<task id="10.1.1">
<title>Register drift runner command in package.json</title>
<action>
Modify `package.json` to add the `"stewardship:drift:check"` script in the `"scripts"` section.
</action>
<acceptance_criteria>
- `package.json` contains `"stewardship:drift:check": "npx tsx scripts/periodic-drift-runner.ts"`.
</acceptance_criteria>
</task>

<task id="10.1.2">
<title>Implement Periodic Drift Runner (scripts/periodic-drift-runner.ts)</title>
<action>
Create `scripts/periodic-drift-runner.ts` to perform the audits:
- Locate all JSON evidence bundles inside `evidence/`.
- Execute `python verify-kit/auditor.py <evidence-file>` for each bundle.
- Execute the environment drift check (`npx tsx scripts/drift-analyzer.ts`).
- Execute the constitutional freeze check (`npx tsx scripts/stewardship-drift-detector.ts`).
- Write alert logs to `DRIFT_ALERTS.json` if any checks fail.
- Support a `--daemon` or `--interval <ms>` option for background execution.
</action>
<acceptance_criteria>
- Script is written, compiles cleanly without type warnings, and handles errors with detailed logs.
</acceptance_criteria>
</task>

<task id="10.1.3">
<title>Run Drift Runner Locally & Inject Failure to Verify Alerts</title>
<action>
1. Run the script against clean codebase files:
   ```bash
   pnpm run stewardship:drift:check
   ```
   *Expected: All checks pass.*
2. Create a modified copy of an evidence file with a bad signature or fields (`evidence/tampered_test.json`).
3. Run the script:
   ```bash
   pnpm run stewardship:drift:check
   ```
   *Expected: Fail, exit code 1, and DRIFT_ALERTS.json created with mismatch details.*
4. Clean up `evidence/tampered_test.json` and delete `DRIFT_ALERTS.json`.
</action>
<acceptance_criteria>
- Script executes correctly on valid evidence.
- Mismatch detection triggers failure exit code and correctly populated `DRIFT_ALERTS.json`.
</acceptance_criteria>
</task>
