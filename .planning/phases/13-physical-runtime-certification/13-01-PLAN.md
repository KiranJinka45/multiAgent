# Phase 13, Plan 1: Physical Runtime Certification

## Objective

Validate execution on a confirmed physical or nested virtualization Linux host with active TPM quote verification (requirement `OPS-MAINT-PHYS-01`), ensuring that ZTAN can execute under native hardware and hypervisor constraints.

---

## Tasks

<task id="13.1.1">
<title>Implement Physical Hardware Validation Script (scripts/validate-physical-hardware.ts)</title>
<action>
Create `scripts/validate-physical-hardware.ts` to execute physical host verification checks:
- Detect `/dev/kvm` presence and accessibility.
- Detect `/dev/tpm0` presence and accessibility.
- Check if `firecracker` and `jailer` are on the path.
- Spawn a real Firecracker microVM instance under KVM using `PhysicalFirecrackerAdapter`.
- Execute a command inside the guest via vsock, check the output, and kill the VM.
- Generate a TPM quote (or mock TPM quote if `/dev/tpm0` is absent and `ZTAN_MOCK_TPM=true` is set).
- Verify the TPM quote using the cryptographic `AttestationVerifier`.
- Save the results into `physical-host-attestation.json`.
- Create a human-readable certification log `PHYSICAL_HARDWARE_CERTIFICATION.md`.
</action>
<acceptance_criteria>
- Script `scripts/validate-physical-hardware.ts` is created and typechecks cleanly.
</acceptance_criteria>
</task>

<task id="13.1.2">
<title>Configure Run Command in package.json</title>
<action>
Modify `package.json` to register the command script:
```json
"stewardship:physical:validate": "npx tsx scripts/validate-physical-hardware.ts"
```
</action>
<acceptance_criteria>
- `package.json` contains the `stewardship:physical:validate` script.
</acceptance_criteria>
</task>

<task id="13.1.3">
<title>Run Validation Script and Verify Results</title>
<action>
Execute the validation runner inside WSL2 Ubuntu:
```bash
wsl -d Ubuntu sh -c "cd /mnt/c/multiagentic_project/multiAgent-main && npx tsx scripts/validate-physical-hardware.ts"
```
Confirm that:
- Real Firecracker VM starts successfully.
- Vsock guest execution completes and returns output.
- VM is destroyed cleanly with zero orphan processes.
- Attestation quote verifies successfully.
- `physical-host-attestation.json` and `PHYSICAL_HARDWARE_CERTIFICATION.md` are created.
</action>
<acceptance_criteria>
- The validator script exits with code 0.
- Output files exist and contain valid verification evidence.
</acceptance_criteria>
</task>
