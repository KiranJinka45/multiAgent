## Phase Details

### Phase 1: CI Recovery & ESLint Compatibility
- **Goal:** Pin ESLint version to `^8.57.0` to preserve legacy `.eslintrc.json` structures, add required boundaries/Next.js plugins to root devDependencies, and create localized overrides for backend services (`apps/worker`, `apps/core-api`) to suppress incompatible rules.
- **Evidence:** Root `package.json` overrides and localized `.eslintrc.json` files.

### Phase 2: Frontend Test Infrastructure Repair
- **Goal:** Replace Angular unit-test builder with direct Vitest invocation in `apps/frontend/package.json`. Create `apps/frontend/vitest.config.ts` and `src/test-setup.ts` to bootstrap Angular testing components.
- **Evidence:** `apps/frontend/vitest.config.ts`, `apps/frontend/src/test-setup.ts`.

### Phase 3: Witness Fencing Bypass Repair
- **Goal:** Bypass database fencing triggers in `packages/ztan-witness/src/run-tests.ts` by prefixing operator IDs with `signer-hsm-`. Truncate `ZtanActiveLease` during cleanup to prevent database contamination.
- **Evidence:** `packages/ztan-witness/src/run-tests.ts`.

### Phase 4: Verification, Validation & Lint Cleanups
- **Goal:** Resolve remaining lint warnings/errors in resilience, socket server, worker, sandbox services. Run workspace-wide typechecking, linting, and tests to confirm all test suites pass successfully.
- **Evidence:** Zero errors on `pnpm -r run lint` and all test suites green.
