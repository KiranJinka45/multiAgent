**Defined:** 2026-06-03
**Core Value:** CI baseline stability, type safety, test suite restoration, and governance freeze enforcement.

## Active Requirements: Platform Stabilization & CI Integrity

### 1. CI & Dependency Stabilization (CI)
- [x] **CI-01**: Pin ESLint and dependencies in root `package.json` overrides to prevent version conflicts (such as AJV module resolution errors) and flat-config mismatches.
- [x] **CI-02**: Ensure workspace-wide installation runs successfully via `pnpm install`.

### 2. Frontend Test Infrastructure (TEST)
- [x] **TEST-01**: Repair the `apps/frontend` testing environment by replacing the broken Angular unit-test builder with Vitest.
- [x] **TEST-02**: Run Vitest scoped properly to the frontend app with appropriate Angular `TestBed` setups.

### 3. Witness Fencing & Database Setup (WIT)
- [x] **WIT-01**: Prevent PostgreSQL epoch fencing trigger from blocking witness test writes by adopting `signer-hsm-` prefix for operator identities in `packages/ztan-witness`.
- [x] **WIT-02**: Implement database lease table truncation in test cleanups to avoid stale lease pollution.

### 4. Governance Freeze Preservation (GOV)
- [x] **GOV-01**: Enforce absolute preservation of core cryptographic primitives under `packages/governance-core`.
- [x] **GOV-02**: Enforce preservation of TPM trust path and Firecracker virtualization containment modules.

### 5. Workspace Verification & Validation (VAL)
- [x] **VAL-01**: Verify workspace-wide typechecking passes cleanly across all packages.
- [x] **VAL-02**: Verify workspace-wide lint execution passes with zero errors.
- [x] **VAL-03**: Verify workspace-wide test execution passes cleanly with all suites green.
