# Requirements: Nexus ZTAN

**Defined:** 2026-06-06
**Core Value:** A replayable infrastructure reliability platform focused on bounded replay determinism under controlled operational assumptions, replay durability, operational clarity, and sustainable long-term maintenance.

## v1 Requirements

### Infrastructure Certification (OPS-INFRA)

- [x] **OPS-INFRA-01**: Document clean deployment process from scratch in `INFRASTRUCTURE_CERTIFICATION.md`.
- [x] **OPS-INFRA-02**: Successfully build all required Docker images locally without dependency resolution errors.
- [x] **OPS-INFRA-03**: Verify that the local/staging Kubernetes deployment succeeds.
- [x] **OPS-INFRA-04**: Verify all virtualized and containerized services become healthy under orchestration.
- [x] **OPS-INFRA-05**: Implement and pass smoke tests for the deployed environment.

### Disaster Recovery Replay (OPS-DR)

- [ ] **OPS-DR-01**: Successfully capture operational state backup of PostgreSQL coordination DB and Redis queues in `DR_CERTIFICATION.md`.
- [ ] **OPS-DR-02**: Verify state destruction protocol by clearing active coordination DB and Redis states.
- [ ] **OPS-DR-03**: Execute recovery restore script to reconstruct the system to the backup point.
- [ ] **OPS-DR-04**: Perform verification smoke tests to confirm state recovery and lease replay logic continues correctly.

### Cross-Version Compatibility Matrix (OPS-COMPAT)

- [ ] **OPS-COMPAT-01**: Map and verify compatibility of v1.8, v1.9, and v1.10 auditors with evidence generated by their respective versions in `COMPATIBILITY_MATRIX.md`.
- [ ] **OPS-COMPAT-02**: Verify that the v1.9 auditor successfully parses and validates v1.8 generated evidence.
- [ ] **OPS-COMPAT-03**: Verify that the v1.10 auditor successfully parses and validates v1.8 generated evidence.
- [ ] **OPS-COMPAT-04**: Verify that the v1.10 auditor successfully parses and validates v1.9 generated evidence.

### Dependency Rationalization (OPS-DEP)

- [ ] **OPS-DEP-01**: Prune all unused production and dev dependencies identified in `DEAD_CODE_INVENTORY.md` across packages.
- [ ] **OPS-DEP-02**: Remove unused files and seeders approved for pruning (e.g., `packages/db/prisma/seed.ts` if not needed).
- [ ] **OPS-DEP-03**: Document final dependency inventory lock in `DEPENDENCY_AUDIT.md`.

### Reproducibility Bundle (OPS-BUNDLE)

- [ ] **OPS-BUNDLE-01**: Assemble the independent third-party validation kit (`verify-kit/`, `evidence/`, `runbooks/`) in `REPRODUCIBILITY_CERTIFICATION.md`.
- [ ] **OPS-BUNDLE-02**: Verify that a clean developer environment can reproduce the verification process using the bundle without manual codebase access.
