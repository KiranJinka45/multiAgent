# ZTAN Cross-Version Compatibility Matrix

This document maps and verifies the compatibility of ZTAN auditors with evidence generated by their respective versions, ensuring long-term auditability and zero-trust verification consistency.

## 📊 Compatibility Matrix

The following matrix represents the verified compatibility between ZTAN Runtime Evidence formats and ZTAN Auditor versions:

| Runtime / Evidence Version | Auditor v1.8 | Auditor v1.9 | Auditor v1.10 (Current) |
| :--- | :---: | :---: | :---: |
| **v1.8 (Attestation-Only)** | ✅ Compatible | ✅ Compatible | ✅ Compatible |
| **v1.9 (Rekor Logs)** | ❌ Unsupported | ✅ Compatible | ✅ Compatible |
| **v1.10 (Threshold/ZK)** | ❌ Unsupported | ❌ Unsupported | ✅ Compatible |

* **✅ Compatible**: The auditor correctly parses, validates, and anchors the evidence without error.
* **❌ Unsupported**: The auditor does not support newer features (e.g. Rekor logs, threshold cryptography, or Zero-Knowledge stability proofs) and will reject or fail to verify the envelope.
