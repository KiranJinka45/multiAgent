# Institutional Dashboard Spec (V1.0)

## 1. Constitutional Command
The Institutional Dashboard is the primary operational surface for managing ZTAN at civilizational scale. It transforms complex architectural data into actionable institutional cognition.

## 2. Layered Views
The dashboard provides four distinct cognitive layers:
- **Executive**: High-level institutional survivability and stability summaries.
- **Operator**: Actionable operational telemetry and incident management.
- **Auditor**: Forensic replay and Merkle-linked lineage inspection.
- **Archaeologist**: Historical governance reconstruction and evolution analysis.

## 3. Cryptographic Traceability
Every claim made in the UI must be cryptographically traceable to its underlying replay evidence. Clicking any dashboard metric allows the user to "drill down" into the raw forensic lineage.

## 4. Trust Visibility
The dashboard operationalizes civilizational visibility by rendering federation topologies, semantic alignment maps, and long-term sociological health metrics (fatigue, entropy).
