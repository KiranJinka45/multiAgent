# ZTAN Operator Readiness Standard

Ensuring that institutional operators are competent and resilient is a prerequisite for ZTAN operational legitimacy.

## Certification Levels

| Level | Requirements | Capabilities |
| :--- | :--- | :--- |
| **BASIC** | Completion of ZTAN-101 Simulation | Read-only access to transparency reports. |
| **ADVANCED** | 90% score on recovery drills | Pilot lifecycle state management. |
| **ELITE** | Zero-failure record in major incidents | Governance root anchoring and root-key rotation. |

## Readiness Scoring

The `OperatorReadinessValidator` measures readiness based on:

- **Competence Score**: Historical performance in simulation labs.
- **Procedural Compliance**: Adherence to IRM playbooks during incidents.
- **Cognitive Load Index**: Real-time monitoring of operator fatigue and telemetry overload.
- **Incident Response Time**: Latency between detection and first remediation action.

## Commands

- `ztanctl support certify`: Start the certification simulation.
- `ztanctl support readiness`: Generate a signed readiness certificate.
