# Invariant Consensus Protocol (V1.0)

## 1. Negotiating Shared Interpretation
When core institutional invariants (Determinism, Monotony, etc.) require clarification or refinement, federations engage in the Invariant Consensus Protocol.

## 2. Interpretation Proposals
An organization can propose a specific meaning for an invariant. This proposal must be:
- **Consistent**: With historical institutional lineage.
- **Verifiable**: Through replay evidence.
- **Explainable**: To future archaeological systems.

## 3. Global Invariant Consensus
Consensus is achieved when a majority of active federations (weighted by reputation) verify and accept the interpretation. This process anchors the "Semantic North Star" for the entire civilizational network.

## 4. Invariant Protection
The protocol prevents "Semantic Hijacking," where a rogue federation attempts to re-interpret invariants to bypass constitutional safeguards.
