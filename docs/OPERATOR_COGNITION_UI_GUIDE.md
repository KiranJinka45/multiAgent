# Operator Cognition UI Guide (V1.0)

## 1. Designing for the Human Institution
The Operator Cognition UI Guide outlines the design principles for ZTAN's operational surface. The goal is to reduce cognitive load while maintaining constitutional truthfulness.

## 2. Layered Complexity
Information is layered by audience. High-level summaries are provided first, with "progressive disclosure" allowing experts to access raw telemetry and forensic depth as needed.

## 3. Constitutional Integrity
The UI must never "normalize" away risk. If the system is in a degraded or ambiguous state, the interface must clearly communicate the constitutional implications to the human operator.

## 4. Stability Over Novelty
The design prioritizes clarity, stability, and seriousness over visual novelty. The goal is to create an interface that feels like "Institutional Infrastructure"—dependable, predictable, and historically grounded.
